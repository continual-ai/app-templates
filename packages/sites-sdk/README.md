# @continual/sites-sdk

Frontend SDK for sites generated by the Continual `create-site` skill. Provides a typed wrapper
around the Continual runtime tool-call contract that the in-thread preview panel and the
published Sites Worker both speak.

## Usage in a site

```ts
import { callContinualToolJson, ContinualRuntimeError } from "@continual/sites-sdk";

const { threads } = await callContinualToolJson<{ threads: Array<{ id: string }> }>({
  appInstallationId: "system-tools",
  name: "platform_api",
  arguments: { command: "threads list", options: { pageSize: 10 } },
});
```

The SDK auto-detects whether the page is in the in-thread preview (URL params /
sessionStorage carry a token) or on a published private site (same-origin Worker routes) and
uses the right transport. Site code does not branch on this.

## Test-call script

Used by the agent to verify a tool call works before wiring it into a component.

```sh
# After `sites preview`, mint a token via `sites preview-token` and then:
CONTINUAL_PREVIEW_TOKEN=<jwt> \
CONTINUAL_APP_ORIGIN=https://app.continual.ai \
pnpm exec tsx node_modules/@continual/sites-sdk/scripts/call.ts \
  system-tools platform_api '{"command":"threads list"}'
```

## Upgrades

The SDK is consumed via `workspace:*` from the `site-templates` repo cloned at
`/opt/site-templates`. To pick up SDK changes, the skill runs `git pull` in that directory at
activation time. No per-site versioning or vendoring.
