# Working in this App (Next.js)

This is a Next.js App Router application deployed to Cloudflare Workers through OpenNext.
Run `pnpm dev` for framework-native local development. Keep server behavior in Route Handlers,
Server Actions, or server-only modules; browser components call relative routes on this App.

The App serves from `/` locally and at the root of its published hostname. Keep internal links and
API calls relative to the App root, such as `/settings` and `/api/threads`.

Use `createServerClient` from `@continual/sdk/server-client` for server-side Continual tool calls and
record each exact Connection ID and tool name for publication. Never pass a runtime assertion or
execution token to the browser. Keep the exact `@continual/sdk` version declared by the template
unless the project intentionally upgrades it.

Prefer React Server Components for initial server-owned data and use client requests for refresh or
interaction. Keep server/client output deterministic, including an explicit timezone for formatted
dates. Treat Continual tool output as its declared structured result rather than guessing alternate
envelopes, and resolve relative Continual UI routes with the server client's `url(...)` helper.

The sandbox proxy origins are configured in `next.config.ts`. Add provider-specific values through
`CONTINUAL_ALLOWED_DEV_ORIGINS` as a comma-separated list when using another development proxy.
`next-env.d.ts` is generated by Next.js and intentionally ignored by Git.

Run `pnpm check` and `pnpm bundle:continual`. The bundle command builds the OpenNext Worker and
writes its Wrangler production output beneath `.continual/wrangler`. Publish only this App from the
project root with:

```sh
pnpm exec continual deploy --app <app-id> --name "<display name>" \
  --app-dir apps/<directory>
```
